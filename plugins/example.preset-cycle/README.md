# 预设轮换

本插件是**教学示例**，用于演示插件开发，也可实际使用。

按主界面预设列表的顺序循环切换当前游戏的组合，便于快速对比不同搭配。需要宿主 1.0.0、SDK 2.0。

启用后保持待命，首次命令或快捷键触发时才加载。配置通过 `ctx.configuration` 读取，待命时也可修改。

## 使用

1. 在主界面创建组合预设，并配置当前游戏的部署目录。
2. 启用插件后，在插件详情的「操作」区或「插件命令」中执行「切换到上一个预设」或「切换到下一个预设」。
3. 默认快捷键为 `Ctrl+Alt+PgUp` 和 `Ctrl+Alt+PgDown`，只在应用内生效。冲突或需要改绑时打开「设置 → 快捷键」。
4. 默认跳过默认预设，可在插件详情勾选「轮换时包含默认预设」。

轮换使用宿主返回的顺序；默认预设排在前面，其他预设按创建时间排列。到列表末尾后回到开头。
当前预设不在候选项中时，向后切换选择第一项，向前切换选择最后一项。没有其他候选项时只显示提示。

切换通过宿主任务队列应用预设及其变体引用，会实际改变 Mod 部署。任务进行中再次点击不会排入额外切换；
只有最终结果 `ok` 为真时才提示成功。失败后可处理任务提示并重试。停用插件会请求取消未完成任务，
取消是否回滚取决于宿主事务所处阶段，应以宿主最终任务结果为准。

## 教学重点

- `select_preset()`：独立、可测试的选择规则；业务身份和界面名称分离。
- `_switch()`：查询当前游戏、检查候选项和忙碌状态、提交 `ctx.presets.apply()`。
- `_on_finished()`：任务成功与失败分支；注册回调前先保存任务，兼容立即完成的结果。
- `deactivate()`：禁止后续反馈并调用公开的 `task.cancel()`，不阻塞主线程等待。

`mods:write` 用于应用预设；`mods:read` 读取列表；`storage` 保存筛选；其余权限声明设置和快捷键。
插件不直接修改数据库、预设文件或部署目录。开发规范与完整接口说明见应用的
`docs/d3dxSkinManage-Plus 插件开发指南.html`；源码位于 `docs/tutorials/zh/插件开发指南.md`。
本目录的清单、入口、语言包和说明文件可单独打成 ZIP 安装。
