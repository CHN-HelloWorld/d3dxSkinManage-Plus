## 第 8 章 · 数据、备份与排障

### 8.1 先找到实际数据根目录

![普拉莎陪你备份和排查问题](../../images/plusa/supplement/备份排障.webp)

程序优先把个人数据保存在程序所在目录。程序目录不可写时，会使用 Windows 用户数据目录，通常为：

```text
%LOCALAPPDATA%/d3dxSkinManage-Plus/
```

可通过「打开语言包文件夹」「打开插件目录」「打开日志目录」核对当前使用的位置，再确认同一数据根下的 `config/`、`data/`。

单文件发行包也附带语言、插件、教程和媒体资源目录。迁移时保留完整发行包，不要只留下 exe。

### 8.2 需要保留哪些文件

| 位置 | 内容 | 备份建议 |
| --- | --- | --- |
| `config/settings.json` | 程序偏好与快捷键覆盖 | 保留 |
| `config/games.json` | 游戏列表、路径、激活游戏、当前组合、社区匹配 | 保留 |
| `config/plugin_state.json` | 插件启用、信任等状态 | 保留 |
| `config/languages/` | 默认及自定义语言文件 | 保留，特别是自行修改的内容 |
| `data/mod_index.db` | 当前资源和部署索引 | 关闭程序后备份 |
| `data/presets.json` | 所有游戏的组合预设 | 保留 |
| `data/<游戏资源目录>/mods/` | 分类目录、完整 Mod 容器 | 必须保留 |
| `data/<游戏资源目录>/` 中的偏好与其他记录 | 游戏私有状态、变体工作状态、预览等 | 整个目录一起备份 |
| `data/downloads/` | 下载源包及队列信息 | 有未安装或需要留档的包时保留 |
| `plugins/` 与插件个人存储 | 已安装插件及其数据 | 需要继续使用时保留 |
| `cache/` | 可再生缓存 | 不作为唯一备份来源 |
| `logs/` | 排障日志 | 出问题时保留相关会话 |
| 外部加载器和部署目录 | 加载器配置、受管部署及手动资源 | 有自定义或手动内容时单独备份 |

完整容器内的 `.d3dxmod`、`.d3dxmeta/` 都属于必要数据。类别目录中的 `.d3dxcategory` 也要保留。

命名变体保存在 `.d3dxmeta/variants/`。备份时需同时保留完整 Mod 容器和 `presets.json`，才能恢复组合及其引用的外观方案。

### 8.3 推荐的完整备份流程

1. 等导入、导出、部署、更新和恢复任务结束。
2. 正常退出程序；若游戏或加载器仍在写配置，也先结束相关操作。
3. 复制实际数据根中的 `config/`、`data/`、`plugins/` 及需要的外部素材。
4. 另存自定义加载器配置与部署目录中的手动资源。
5. 将备份放在与源数据不同的位置，并抽查容器、元数据和预设文件。

程序运行时数据库可能同时使用 `-wal`、`-shm` 等文件。正常关闭后再复制，避免拿到时点不一致的数据。不要只挑一个正在写入的数据库文件拷走。

单独分享某个 Mod，使用总览的导出并选择附带元数据；分享分类结构则使用 `.d3dxcp`。两者都不能代替整机数据备份。

### 8.4 换目录、换磁盘或换电脑

迁移整个管理器时，先按上节备份并退出，再复制完整发行包和个人数据。新位置启动后逐个检查：

- 游戏可执行文件和加载器路径。
- 「Mod 文件夹」指向的实际部署位置。
- 外部背景图片、视频或 WE 场景及程序路径。
- 自装字体、语言包和插件是否仍可用。
- 游戏资源盘是否已连接。

程序内受管的部分路径可相对数据根保存；外部游戏、加载器和媒体路径仍可能需要重新填写。

改变部署位置优先使用「游戏」页提供的迁移确认。不要把一份不完整部署目录当成新的 Mod 库重新导入，尤其不能丢弃身份标记后再混用旧索引。

### 8.5 文件身份、校验与恢复提示

程序会在操作前核对受管源文件、元数据和部署记录。以下变化可能导致写入被阻止：

| 提示类型 | 优先处理 |
| --- | --- |
| 文件不存在或磁盘离线 | 接回磁盘，检查实际路径 |
| 文件正在被占用 | 关闭对应编辑器、预览或游戏相关操作后重试 |
| 源文件或元数据已变化 | 重新选择对象、刷新并核对修改来源 |
| 身份不一致或无法确认归属 | 保留完整容器与记录，检查是否只复制或替换了部分文件 |
| 校验不一致 | 保留原包和错误信息，确认文件是否损坏或被改动 |
| 有未完成事务 / 回退 / 清理 | 等待恢复，或按提示重新启动并重试 |

这类提示用于避免对错误对象继续操作。**不要删除标记、数据库或事务记录来消除提示。** 需要恢复的文件内容和路径信息可能就在这些记录里。

### 8.6 常见问题

| 现象 | 排查方法 |
| --- | --- |
| 启动后游戏列表为空 | 确认使用了正确的数据根；首次安装本来就是空列表 |
| 页面被激活提示遮住 | 在「游戏」页双击目标游戏 |
| 无法导入到根级 | 先进入类别 |
| 已导入却找不到 | 检查当前游戏、类别、搜索词、类型、分级和标签条件 |
| 启用后游戏无变化 | 检查部署位置、加载器是否运行、Mod 适配版本，以及是否已重载 |
| 空格、F2 等没有执行 | 先单选总览中的项目并移出文本框，再核对自定义绑定 |
| 按键页没有绑定 | Mod 的 INI 未提供可识别绑定，或读取尚未完成 |
| 变体无法保存 | 启用 Mod，确认支持持久化变量，并让加载器先写入当前配置 |
| 变体显示状态未确认 | 回游戏保存配置后重新读取，或明确选择使用默认值补齐 |
| 改了变体，游戏仍是旧外观 | 按加载器配置重载，避免未写入的游戏状态覆盖已保存选择 |
| 在线页提示未收录 | 核对游戏英文名和站点收录情况 |
| 下载失败或速度慢 | 测试网络与代理，检查磁盘空间，再重试 |
| 下载完成但未安装 | 核对待安装目标，切回所属游戏，再查看任务结果 |
| 更新检测不完整 | 处理联网或来源读取错误后重新检查 |
| 程序没有可用更新 | 检查是否配置更新源，以及发行者是否发布新包 |
| RAR 可读却不能导出 RAR | 创建 RAR 需要安装 WinRAR |
| 图片占用较高 | 调整图片内存额度或清理图片缓存，不要清空资源数据 |
| 视频或 WE 场景不播放 | 检查素材路径、格式、完整场景目录和本机 WE 程序 |
| 重建后仍有缺项 | 查看报告中的无效元数据、身份冲突或源文件缺失，逐项处理 |
